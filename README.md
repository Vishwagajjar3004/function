Python Functions Project
Overview

This project contains five reusable Python utility functions that demonstrate common programming concepts such as string processing, exception handling, dictionary manipulation, list operations, and recursion.

The project also includes test cases for each function to verify correctness.

Functions Included
1. clean_text(text)
Cleans a text string by:

Converting text to lowercase
Removing special characters
Removing extra space

2. safe_divide(a, b)
Performs safe division between two numbers.
Returns None if division by zero occurs.

3. flatten_dict(d)
Converts a nested dictionary into a single-level dictionary.

4. chunk_list(lst, size)
Splits a list into smaller chunks of a specified size.

5. count_words(text)
Counts the total number of words in a string.
